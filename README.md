
# YuvaIntern Week 2: Responsive Web Design

## Project
FlexTech — Responsive Web Design Showcase

## Objective
To develop a responsive webpage that works smoothly on desktop, tablet, and mobile screens.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Media Queries
- GitHub Pages

## Design Methods
Semantic HTML elements are used to organize the webpage. CSS Grid creates the feature and showcase layouts. Flexbox aligns navigation, buttons, and footer content. Fluid font sizes and flexible widths improve adaptability.

## Responsive Breakpoints
- Desktop: above 900px
- Tablet: 900px and below
- Mobile: 640px and below
- Small phones: 380px and below

## Testing
The webpage should be checked at 1440px, 768px, and 375px viewport widths. Navigation links, text readability, card layouts, and horizontal overflow should be checked.

## Challenges and Solutions
Desktop columns may not fit on small screens. Media queries change the layout to one column on mobile. Navigation links can wrap, and button widths adjust for small screens.

## Conclusion
This project demonstrates responsive web design using semantic HTML, CSS Grid, Flexbox, and media queries.
